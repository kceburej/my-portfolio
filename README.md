# Портфолио дизайнера — Екатерина

Персональный сайт-портфолио с тремя учебными проектами:

- **«Осиль смолу»** — фирменный стиль для студии эпоксидной смолы (логотип, палитра, паттерн, мерч)
- **«Медиалог»** — концепт мобильного приложения для сохранения впечатлений от фильмов и книг (UX/UI)
- **Буклет музея советских игровых автоматов** — полиграфия с игровой механикой

## Технологии

Чистый HTML/CSS/JS без сборщиков и зависимостей. Шрифты Fraunces + Inter (Google Fonts). Поддержка светлой/тёмной темы, адаптивная вёрстка, анимации появления при скролле.

## Как запустить локально

Просто откройте `index.html` в браузере — никакой установки не требуется.

## Публикация на GitHub Pages

1. Создайте новый репозиторий на GitHub и загрузите туда содержимое этой папки (`index.html` и папку `assets/`)
2. В репозитории откройте **Settings → Pages**
3. В разделе **Source** выберите ветку `main` и папку `/ (root)`
4. Сохраните — через 1-2 минуты сайт будет доступен по адресу `https://<ваш-логин>.github.io/<название-репозитория>/`
